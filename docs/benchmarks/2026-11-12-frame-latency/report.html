frame latency 1 vs 2

crab-breeze-lessons task 1.2 (the uncapped half) and the first sitting of lighting-perf. One exe (57d94b5, the lighting-perf instruments), the same assets, --frame-latency 1 (the default until now) against --frame-latency 2 (wgpu's default, what Crab Breeze runs). Machine: RTX 3070 (Vulkan), i7-9700F, Windows 10, window 1440 x 900, uncapped (--no-vsync), release build, 3 repeats per variant interleaved, clock at 10:00. The sitting started at 06:51 after waiting 13.5 min for another agent's release build to end (nothing else ran during it; CPU sample in cpu/).

The owner's targets are 120 fps (8.3 ms) at the 95th percentile and never below 60 fps (16.7 ms) at the 99th.

Findings

  • A queue of two frames takes 3.2-4.3 ms off p50 in every scenario, and more off the tail. p50 / p95 / p99, latency 1 then 2 (median of 3): - rain-stroll: 14.18 / 21.63 / 30.30 to 10.49 / 16.10 / 23.34 (-3.69 / -5.53 / -6.96) - storm: 10.17 / 16.61 / 24.04 to 6.67 / 12.49 / 16.86 (-3.50 / -4.12 / -7.18) - walk: 9.05 / 12.07 / 16.09 to 5.81 / 8.47 / 10.52 (-3.24 / -3.60 / -5.57) - town: 11.16 / 19.91 / 28.92 to 6.91 / 13.60 / 18.73 (-4.25 / -6.31 / -10.19)
  • The spread between repeats is far smaller than that: at p50, 0.20 and 0.19 ms on rain-stroll, 0.07 and 0.19 on storm, 0.76 and 0.29 on walk. town is noisy at latency 1 (10.30, 11.16, 16.08) and steady at 2 (6.79-7.36); every one of its latency-2 runs is faster than every one of its latency-1 runs.
  • The GPU does the same work either way (GPU total p50 9.75 / 9.86 ms on the stroll, 5.88 / 5.94 in the storm, 5.13 / 5.35 on the walk). With a queue of one, the render world could not start the next frame until the GPU had finished the last, so CPU and GPU time partly added up. With two they overlap: the storm and the walk now run at about their GPU time, and the stroll is GPU-bound (10.5 ms wall against 9.9 ms of GPU).
  • Decision (crab-breeze-lessons 1.3, recommendation taken (ask only with screenshots)): 2 is the default from this commit; --frame-latency 1 stays. The price is up to one frame more between input and photon. Mouse look still applies each frame's raw displacement (CLAUDE.md), and nothing else about input changes. Every later lighting-perf A/B runs at the new default.
  • The GPU per pass on the stroll (latency 2, p50): the terrain pass (main_transparent_pass_3d, which holds L8's traces) 4.34 ms, the sun's cascades (planet_shadow) 2.03 ms, the rain volume 1.44 ms, the opaque pass 0.57 ms, the lens 0.29 ms, bloom 0.09 ms, the reflection capture 0.03 ms. That price list is what the rest of lighting-perf works from.

How this was measured

  • Uncapped only. The vsync half of crab-breeze-lessons 1.2 (counting refreshes missed with vsync on) is not run here; that task stays open.
  • Input latency is not measured. The extra frame is the mechanism's cost, read, not timed.
  • Three repeats. The fresh world's planet rebuild (6.2-6.9 s, every run) is left out of the statistics (lighting-perf 1.3) and listed per scenario.
  • The raw CSVs and logs are local: output/perf/2026-11-12-frame-latency.
  • revision: 57d94b5 (uncommitted changes)
  • adapter: NVIDIA GeForce RTX 3070 (Vulkan); window 1440 x 900, uncapped (--no-vsync)
  • clock pinned at 10.0 h; first 10.0 s after loading (the ready line, else the first frame) thrown away; 3 run(s) per variant, interleaved
  • budgets: p95 within 8.3 ms (120 fps), p99 within 16.7 ms (60 fps); over marks a miss. Each cell is the median over the valid runs.

Each run starts from a fresh world with the clock pinned at 10:00 and throws away its first 10 s. A cloud run that never found cloud, or a route that never landed, is marked invalid and left out. Traces are binned to 0.1 s: the faint line is each bin's worst frame, the solid line its median. Reproduce with:

python tools/perf_suite.py --scenarios rain-stroll,storm,walk,town --repeats 3 --out output/perf/2026-11-12-frame-latency --exe C:/Users/santi/repos/pbd-perf-main/output/perf/baseline-exe/lighting-perf-instruments/pbd-app.exe --variant lat1 --variant "lat2||--frame-latency 2"
