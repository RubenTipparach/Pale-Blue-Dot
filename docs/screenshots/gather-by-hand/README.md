# Gather by hand (`gather-by-hand`)

Captured 2026-11-16 in a cloud container on lavapipe at 1440x900, with no
GPU, from the fast build on a memory-only new world. They show what the take
looks like, not how smoothly it runs; frame cost was not measured.

Both: `--walk --spawn fields --time 12 --pitch -22 --rain 0 --weather-at 7200 --frames 300`.

| file | flags | what it shows |
| --- | --- | --- |
| `before.jpg` | none | The meadow by the fields spawn, its clutter as the draw rolls it. The mission line reads "Gather by hand: fibre 0/8". |
| `after.jpg` | `--gather-around 30` | The same, after the capture instrument took all 50 pieces within 30 m through the path F takes one: the mission line has moved to "stone 8/9" (the fibre done), the hotbar's last slot holds the loose stone, and the note says the last take. |
| `bush-crop.png` | | 2x crops of the left edge, before and after: the leafy bush (two lumps) under the oak is gone; nothing else moved. |

At 150 frames the "after" shot caught the fine set's own landing dissolve
part way, which the pair here, at 300, does not: the stipple was the
landing, not the take.
