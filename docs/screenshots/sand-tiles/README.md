# sand-tiles screenshots

M13's Sand tab (`docs/mockups/foliage.html#sand`, version 4), rendered with
headless Chromium on SwiftShader in a cloud container with no GPU (2026-11-19).
They show the look, never a frame time.

| Shot | Shows |
| --- | --- |
| `beach-day-today-new.png` | The beach by day, split: today's tile (teal flecks) left, the new shell sand right |
| `beach-night-today-new.png` | The same at night, lit by a torch on the sand and a dim moon |
| `desert-day-today-new.png` | The desert by day, split: today's pale sand left, the new orange-ochre right |
| `desert-night-today-new.png` | The same at night, with torches and a lantern |
| `both-day-new.png`, `both-night-new.png` | Beach and desert side by side, both new |
| `tiles-beach-top.png`, `tiles-desert-top.png` | The flat tile panel: each top tiled 4 x 4, today beside new |

The candidate tiles themselves, tiled 4 x 4 today above new, are
`docs/mockups/sand/sheet.png`.
