Hex Tool Bench

A mockup of the four held tools, drawn on the hex grid, and held in a stubby hex hand. The grid is 4× finer than the first draft: a hex is a quarter as wide, so a tool is sixteen times as many hexes. Each handle lies exactly on row 0, so it is straight at any density. Each hex also has its own depth, so a handle is thick and round and a blade is thin. Nothing here is in the game yet.

How this would go into the game

  • The hexes become the source. Each tool is stored in a RON file as a list of hexes, one colour and one depth each. The mesh is built from that list the way pbd_core::hexel builds it now, and each side wall covers only the height by which a hex stands above its neighbour.
  • The slot icons are drawn from the same hexes, so the icon and the model cannot disagree. Today it is the other way round: the model is sampled from the icon, and that sampling is what made the handles zigzag.
  • The hand is built on a real human hand's bones. tools/gen_held_hand.py loads Blender's Rigify human metarig and takes its right hand: four palm bones, three bones a finger and three for the thumb, at human proportions. It solves the three finger joints so every segment hugs the handle, then searches the thumb so it wraps round and rests on the index finger without passing through. Each bone becomes a stubby hexagonal prism, a third thicker than a real finger, and the back of the hand is one flat block. The fist is closed round a thin handle and scaled up onto each tool's grip, which is what makes it big in view.
  • One source. tools/gen_held_tools.py defines the shapes, the poses and the hand. It writes the data this page draws, and renders the same data in Blender, so the look checked in Blender is the look here.
  • Working end down. Each tool names its working direction in its own drawing (the pick's lower tip, the axe's edge, the shovel's blade face, the rod's reel) and is turned about its handle so that direction points down and ahead. The shovel is held blade-first, ahead and low.
  • 2× size: the reach from grip to head doubles, from 0.23 m to 0.46 m. The grip moves from (0.26, −0.26, −0.48) to (0.31, −0.30, −0.52) so the head does not cover the crosshair and the whole fist is in view.
  • The rod has no line or float, because the game draws the real line from the rod tip.
