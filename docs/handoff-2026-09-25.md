## Gotchas

- **The game reads `assets/` from the checkout at run time.** An old exe runs
  the new shaders unless the suite's `assets` field lays the old ones over
  (it restores them after every run).
- **`partition` is a reserved word in WGSL** (naga refuses it).
- **`LOD_FADE skipped`** in the log is expected on the first landing after
  startup and on some fast-flight landings; it means that landing popped
  rather than risk holes.
- **Long heredocs through the Bash tool failed** twice ("unexpected EOF");
  patch scripts written to the scratchpad and run with Python were reliable.
- **A Remote Control session** (`claude remote-control --name Pale-Blue-Dot`)
  was started in its own window at the owner's request; it shares this
  working tree.
